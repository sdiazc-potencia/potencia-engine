# Contexto vivo de la marca

Acá va todo lo que Claude debe tener presente al generar contenido para esta marca, además del manual (`../cliente.md`) y la voz (`../prompt_maestro.md`):

- `reuniones/YYYY-MM-DD-tema.md` — **resúmenes** de reuniones (no transcripciones crudas): decisiones, lineamientos, temas prohibidos/prioritarios, fechas clave.
- Briefs de campañas, lanzamientos o promos vigentes (con fecha de vencimiento si la tienen).

Regla: si algo de acá contradice a `prompt_maestro.md`, lo más reciente manda — y conviene actualizar el prompt maestro.
